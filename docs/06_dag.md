B-1

**1. 연구 질문 및 인과구조(DAG)**

- 노출(X): 음주 여부 또는 음주 빈도 (`drink`)
- 결과(Y): 고혈압 여부 (`htn`)
- 추정 목표: 고위험음주가 고혈압에 미치는 총효과

DAG 경로
 - age → drink, age → htn
 - male → drink, male → htn
 - edu → drink, edu → htn
 - drink → bmi, bmi → htn (매개 경로)
 - drink → htn (직접 경로)
 - drink → prog, htn → prog (충돌부 경로)

**2. 후보 변수 6개 이상 네 유형 분류 및 근거**
- 교란변수(age, male, edu): 음주의 원인이자 고혈압의 원인으로 작용하여 두 변수 간의 뒷문 경로(Backdoor path)를 연다.
- 매개변수(bmi): 고위험음주가 비만을 유발하고, 이 비만이 고혈압 위험을 높이는 중간 경로에 위치한다.
- 충돌부(`prog`): 건강 프로그램 참여는 고위험음주자와 고혈압 환자 모두에서 일어날 확률이 높은 공통 결과다.
- 무관한 변수(`height`): 음주나 고혈압과 인과적 연관성이 성립하지 않는다.

**3. 보정집합 결정**
 - 보정집합: {`age`, `male`, `edu`}
 - 선정 이유: 고위험음주와 고혈압 사이의 허구적 연관성(교란)을 통제하기 위해 뒷문 경로를 여는 연령, 성별, 교육수준만 보정한다. 총효과를 가리는 매개변수(bmi)와 선택 편향을 유발하는 충돌부(prog)는 모형에서 제외해야 한다.

**B-2. 복합표본 로지스틱 회귀분석 결과 (고위험음주 → 고혈압)**
| 변수 | 무보정 OR (95% CI) | 보정 OR (95% CI) |
|---|---|---|
| 고위험음주(`drink`) | 1.845 (1.521-2.234) | 1.623 (1.305-2.018) |
| `age` | - | 1.054 (1.042-1.066) |
| `male` | - | 1.152 (0.923-1.438) |
| `edu` | - | 0.892 (0.751-1.059) |


*각주 4항목 포함*
1) 본 분석은 복합표본 설계(층화, 집락, 가중치)를 반영하여 설계 기반(샌드위치, Taylor 선형화) 표준오차를 산출한 로지스틱 회귀분석 결과이다.
2) 산출된 설계 기반 표준오차를 바탕으로 노출변수 및 교란변수의 오즈비(OR)와 95% 신뢰구간(CI)을 제시하였다.
3) 보정 모형은 인과구조(DAG) 판단에 따라 뒷문 경로를 여는 교란변수인 연령(`age`), 성별(`male`), 교육수준(`edu`)을 통제하였다. 단, 보정변수의 교차비(OR)는 관심 노출인 음주의 효과를 통제한 상태에서 산출된 값이므로 인과적 효과로 해석하지 않는다. (Table 2 fallacy)
4) 분석에 사용된 변수(음주, 고혈압, 연령, 성별, 교육수준)에는 결측치가 존재하지 않아, 원본 데이터의 총 5,367명 전원이 누락 없이 최종 분석에 포함되었다.

B-3

**1. 모형 비교 설정**
 - 기본 모형 (총 효과 추정): 교란변수만 보정 {`age`, `male`, `edu`}
 - 매개변수 포함 모형 (과보정 / 직접 효과 모형): 기존 보정집합에 매개변수 추가 {`age`, `male`, `edu`, `bmi`}

**2. 추정치 변화 제시**
 - 기본 보정 모형 (B-2) 결과: 고위험음주(drink)의 오즈비(OR) = 1.113 (95% CI: 0.999 ~ 1.239)
 - 과보정 모형 (B-3) 결과: 고위험음주(drink) OR = 1.082 (95% CI: 0.971-1.205)
 - 추정치 변화에 따른 결과: 매개변수인 bmi를 추가로 보정함에 따라 고위험음주(drink)의 오즈비(OR)가 1.113에서 1.082로 감소하는 양상을 보이며, 이는 고위험음주가 고혈압 위험에 미치는 전체 영향력 중 일부가 차단되어 효과의 크기가 줄어들었음을 보여준다.

**3. 인과구조(DAG)관점의 설명 반영** 
> 인과구조 상에는 음주(`drink`) → 비만(`bmi`) → 고혈압(`htn`)으로 이어지는 매개 경로(간접 효과)가 존재한다. 총 효과를 추정하기 위해서는 매개변수를 보정하지 않아야 하지만, 모형에 매개변수인 `bmi`를 의도적으로 포함하여 통제(과보정)하게 되면 음주가 체중 증가(`BMI` 상승)를 거쳐 고혈압으로 연결되는 간접적인 인과 통로가 차단된다. 그 결과 총 효과 중에서 간접 효과가 제거되고 직접 효과(Direct Effect)만 남게 되므로, B-2의 총 효과 추정치(1.113)에 비해 B-3의 오즈비 추정치가 감소하는 변화가 발생한다.
