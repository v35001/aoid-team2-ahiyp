B-1

노출 (X): 음주 여부 또는 음주 빈도 (drink)
결과 (Y): 고혈압 여부 (htn)
추정 목표: 고위험음주가 고혈압에 미치는 총 효과

DAG경로
 - age → drink, age → htn
 - smk → drink, smk → htn
 - drink → bmi, bmi → htn
 - drink → sbp, sbp → htn
 - drink → chol, chol → htn
 - drink → htn, htn → death
 - bs → death

| 변수 | 유형 | 인과구조적 근거 | 
| :--- | :---: | :---: | 
| age(연령) | 교란변수 | 연령은 음주 습관과 고혈압 발병 위험 모두에 영향을 주는 선행 공통 원인입니다 |
| smk(현재흡연) | 교란변수 | 흡연은 음주 행동과 밀접하게 연관되며 동시에 고혈압의 주요 교란 요인입니다 |
| sbp(수축기혈압)| 매개변수 | 음주로 인해 직접·간접적으로 상승하여 고혈압 진단으로 이어지는 경로상 변수입니다 |
| bmi (체질량지수)| 매걔변수 | 음주가 체중 증가를 유발하여 고혈압으로 이어지는 경로상의 매개변수입니다 |
| death (사망) | 충돌부 | 고혈압과 공복혈당 등 건강 악화 요인들의 영향을 동시에 받는 공통 결과 변수입니다 |
| bs (공복혈당) | 무관한 변수 | 음주와 고혈압 간의 인과적 경로에 직접 관여하지 않는 별도의 대사 지표입니다 |

보정집합 결정
 - 보정집합 : {age, smk}
 - 선정이유 : 음주와 고혈압 사이의 허구적 연관성(교란)을 통제하기 위해 뒷문 경로를 형성하는 연령(age)과 현재흡연(smk)만 보정한다.
총효과를 가리는 매개변수(bmi, sbp, chol)와 선택 편향을 유발하는 충돌부(death), 그리고 인과 경로와 무관한 변수들(age65, bs)은 모형에서 제외해야 한다.
