B-1
노출 (X): 음주 여부 또는 음주 빈도 (drink)
결과 (Y): 고혈압 여부 (htn)
추정 목표: 고위험음주가 고혈압에 미치는 총 효과

DAG경로
 age → drink, age → htn
male → drink, male → htn
edu → drink, edu → htn
drink -> bmi, bmi -> htn (매개 경로)
drink -> htn (직접 경로)
drink- prog, htn -> prog (충돌부 경로)

| age(연령) | 교란변수 | 연령은 음주 습관(X)과 고혈압(Y) 양쪽 모두에 영향을 미치는 선행 원인이다|
| male(성별) | 교란변수 | 성별은 음주 양상(X)과 고혈압(Y)모두에 영향을 미치는 선행요인이다 |
| edu(교육수준)| 교란변수 | 교육수준은 사회경제적 요인으로서 음주 행태와 고혈압 관리 수준에 동시 영향을 미칩니다 |
| bmi (체질량지수)| 매걔변수 | 음주가 체질량지수를 거쳐 고혈압으로 이어지는 인과 경로상의 매개 역할을 합니다 |
| prog(건강프로그램 참여 여부) | 충돌부 | 음주와 고혈압 두 조건 모두에 의해 참여 확률이 결정되는 공통 결과 변수입니다 |
| height(키) | 무관한 변수 | 키는 음주 행태나 고혈압 발병 경로와 직접적 인과관계가 없는 독립된 변수이다|

보정집합 결정
 보정집합 : age, male, edu
 선정이유 : 선정 이유: 고위험음주와 고혈압 사이의 허구적 연관성(교란)을 통제하기 위해 뒷문 경로를 여는 연령, 성별, 교육수준만 보정한다. 
          총효과를 가리는 매개변수(bmi)와 선택 편향을 유발하는 충돌부(prog)는 모형에서 제외해야 한다.
